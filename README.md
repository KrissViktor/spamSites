# Low-rate background HTTPS requests

Небольшой генератор фоновых HEAD-запросов для Linux и Raspberry Pi OS.
Случайная пауза 0,5–3 секунды между последовательными запросами, без загрузки тел ответов
и переходов по редиректам. После ошибки домен пропускается 30 минут.
Внешние Python-пакеты не нужны. Требуется Python 3.

## Скачать и запустить

Если Git или Python отсутствуют (Debian / Ubuntu / Raspberry Pi OS):

```sh
sudo apt-get update && sudo apt-get install -y git python3
```

Скачать:

```sh
git clone https://github.com/KrissViktor/spamSites.git
```

Запустить в консоли (остановить: Ctrl+C):

```sh
cd spamSites && sh start.sh
```

Вместо запуска в консоли можно запустить в фоне через systemd:

```sh
cd spamSites && sh service.sh start
```

Если вы уже внутри spamSites, повторный `cd spamSites` не нужен.
Сервис ограничен 15% одного ядра CPU и 128 МБ памяти.
Лимит CPU строже 15% общей мощности четырёхъядерного Raspberry Pi 5.
Нужен sudo. Запуск вручную через start.sh не задаёт жёстких лимитов.
После перезагрузки сервис нужно запустить снова; автозапуск не устанавливается.

```sh
sh service.sh status
sh service.sh logs
sh service.sh stop
```

Одно обращение для проверки сети:

```sh
sh start.sh --once
```

Список доменов — HOSTS в cover_traffic.py. Используйте публичные сайты,
допускающие автоматические обращения. Частоту повышать не рекомендуется.

## Ограничения

Это не средство сокрытия реальных посещений. HTTPS-запросы отличаются от
просмотра страниц; видимость доменов провайдеру зависит от DNS, VPN и ECH.
Жёсткого ограничения полосы нет: низкая частота и отсутствие загрузки тел
ответов обычно дают небольшой объём трафика, но его точное значение зависит
от TLS и серверов. Производительность на конкретном Raspberry Pi нужно измерить.
